DeepSeek 额度管理器　Windows x64 完整体验版
版本 0.2.0a3.dev2

打开方式
将 ZIP 完整解压到可写文件夹，双击 DeepSeekQuotaGuardAI.exe。主程序、Chromium 浏览器、4B 网页操作模型和 0.5B 诊断模型都在这个目录里，首次启动无需安装依赖或下载模型。

先看完整工作台
在首页点击“体验示例账本”，将打开一个独立的示例窗口。里面有 Cedar 和 Maple 两个示例名称以及一行待填写。连接示例控制台并读取费用时，程序使用本机 4B 和 Chromium 操作本机模拟页面，无需输入账号或密钥。当前阶段和用时显示在窗口内，首次读费可能需要约一分钟，实际耗时取决于电脑。

Cedar 的初始示例账本有一条 0.80 元的历史记录，个人额度为 1.00 元。模拟平台本次账单为 1.05 元。读取后在“费用核对”查看本次金额、公共额度、有效期间和完整 Tracking ID。Maple 的额度是 -1，会显示为跳过。打开“处理记录”可查看入账和操作证据。示例会话关闭后，其临时账本随之清理；再次打开可从初始数据重新体验。

自己的账本
新建列表时填写总预算和分配人数，再录入平台上的 Key 名称与个人额度。公共人均额度按总预算除以分配人数后向下取整到元。空姓名以及额度为 -1 的行跳过，额度为 0 的受管行在身份核验后可触发处理。表里只填名称，不填完整密钥。内置编辑器自动保存有效输入，Excel 导入会先汇总管理与跳过范围。

正常工作台的登录入口打开独立的官方控制台浏览器。完成官方登录后回到程序读取费用，核对再决定是否开启管理。达到个人或公共阈值的普通 Key 会进入处理。每轮处理完成后，程序才开始等待设置的间隔。账单更新和已在途的请求会影响实际停用时点。

停止与恢复
“停止管理”结束后续轮询，已发出的撤销仍须核实。“中断当前操作”会清理本次浏览器会话。达到额度时，先看费用核对页的金额、命中的额度和证据时间。遇到返回丢失或上次结果未知，打开“处理记录”，选中原操作，点“定位待核实人员”，再从“选中 Key 的操作”核实平台状态。保留原账本和处理记录，直到能核实结果。费用下界、过期读数和完整证据在核对页分别显示。强制删除在选中人员的操作内，确认前会显示该枚 Key 的完整标识。

目录和数据
请保留 _internal、operator-ai 和 local-ai 的名称和相对位置。本版本全新目录的本地资料保存在“用户数据”内。已有旧式账本的目录沿用原账本位置。其他账本可从“工具与设置”选择；原有历史和责任登记请一起保留。模板位于 templates，第三方许可随包附带。

本版用于完整界面体验和离线验证。真实平台上的正额度自动撤销、100 枚同时达额和长期无人值守运行仍待单独验收。
